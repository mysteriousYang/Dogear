# 如何下载github的文件

## git clone

对于会用git的同学来说，直接git clone是最简单快捷的

## 下载整个仓库

对于不太会用git的同学，你在首页的中间靠右的部分有一个绿色的【Code】按钮，你戳一下然后选择【Download Zip】就好了

它会直接把整个仓库打包下下来

不过这个过程可能有点慢而且过程很长（甚至有可能丢失文件），建议还是git clone好些

当然，因为github支持单独下载文件，所以我也把这些图片打包成了PDF，你可以单独下载某一本下来

## 下载单个文件

你可以使用类似资源管理器的方式浏览repo中的文件

单个的PDF文件甚至可以在github上直接阅读

你也可以点击右上角的“↓”按钮下载单个文件到电脑
